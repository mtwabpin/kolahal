Kolahal 0.5.8, package `com.mtwabpin.kolahal`, Android 9 or newer. It installs over 0.5.7 and keeps your data and settings.

- **kolahal-0.5.8.apk**: the full build.
- **kolahal-0.5.8-play.apk**: the Play build, the same app as on Google Play: no screen lock (`lock`, double-tap), no calls in the log and no `update`, and it finds people with Android's contact picker instead of reading your contacts. Play Protect may block either APK when sideloaded in India and some other countries, as both have notification access: install with scanning off, as the install guide says. Both APKs use the same package and key, so either installs over the other.

## What's new

- **Scripts can have widgets.** A script can fill a card on the widgets page, beside your apps' widgets. The script says what to show, and Kolahal draws it in the theme's colours. There are eleven kinds of card:
  - a big number, a few lines of text, a list (its rows can have checkboxes), a ring or bars for progress, a chart;
  - a countdown and a clock for several places, which Kolahal keeps ticking by itself;
  - an agenda of events by day, and a picture with a caption;
  - a row of buttons, and switches that show "working" until the script has done the change.
- **Kolahal's own widgets.** Six more cards in **+ Add**, filled from Kolahal's own data, with no script:
  - **Todos**: tap a row to tick it off. **Reminders** and **Notes**: the next ones, and a tap opens them in the log.
  - **Shortcuts**: up to 8 buttons, each running a command you choose. Select the widget in **Arrange widgets** and tap **Edit shortcuts**.
  - **Now playing**: what's playing, with back, play or pause, and next. **Agenda**: your calendar's next days.
  - The battery card is now called **Battery and network**.
- **You place them, like any widget.** Tap **+ Add** on the widgets page (or run `widget add`): your scripts' widgets are in the **Kolahal** group. A script can't place its own widget. Resize, move and remove it in **Arrange widgets**, where a long-press on the card takes you.
- **Eighteen library scripts have a widget.** Twelve you may already have: `weather`, `forecast`, `aqi`, `crypto`, `hn`, `quote`, `countdown`, `exchange` (currency rates), `releases` (new GitHub releases), `xkcd` (the comic of the day), and `cricket` and `football` (the live score of the match you follow). Six are new:
  - `unlock-chart`: today's unlocks, over a bar for each of the last 7 days.
  - `headlines`: the newest items of a feed you choose.
  - `webnumber`: one number from any JSON address: a price, a count, a sensor at home.
  - `habit`: a habit streak. Tap the card, or type `habit done`, to mark today.
  - `world-clocks`: the time in up to four places.
  - `quick-toggles`: switches for Do Not Disturb and the work profile.
- **A tap does something.** It runs the widget's script again (`weather` then shows its full report in the log), opens a web link (a headline's story), or refreshes the card. A script can't put a terminal command behind a tap.
- **A widget keeps itself current.** Its script fills it on the script's own timer, when you place the widget, and when the widgets page shows it with old content. Old content stays readable, with its age under it ("2 h ago"). After a failed run for the widget, or a failed tap, the card says "Failed 10:42" and keeps what it had.
- **For your own scripts**: add an `@widget <kind> [<size>]` line and call `widget.show{…}` with the kind's fields. An unknown field or a wrong value is an error with the line number, so a typo doesn't pass unseen. `widget.clear()` empties the card, and `allowed("widget")` tells whether you placed it. The scripting guide has every kind and field.
  - Text in a widget can be bold, italic, underlined, struck through or in a theme colour, with `fmt`. A picture must be an https link.
- **Scripts can read your lists**, each only with its own `@uses` line and switch: `todos.list` and `todos.setDone`, `notes.list`, `reminders.list`, `calendar.events` and `feeds.unread`. A calendar list goes straight into an agenda widget.
- **`device.unlocks(days)`**: with a number of days (1 to 30), it returns the unlock counts of the last days as a list, the oldest first. Without one it returns today's count, as before.

## Fixed

- **Locking the private space hides its lines under `log only` too.** Before, its lines already on screen stayed until the log was searched again.

## Safer

- **`script get` no longer switches a shared script on by itself.** A script that asks for access (the internet, your apps, commands and the like) arrives switched off, and a line says what it asks for. Tap the line, or type `script on <name>`, to switch it on and allow that. A script that asks for nothing still arrives on. Get more scripts already showed each permission before Install.
- **A backup can't hide a command behind a Shortcuts button.** When a backup brings shortcuts, the import's review lists each one with its command.
