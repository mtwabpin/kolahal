Kolahal 0.4.12, package `com.mtwabpin.kolahal`, Android 9 or newer. It installs over 0.4.11 and keeps your data and settings.

- **kolahal-0.4.12.apk**: the full build.
- **kolahal-0.4.12-play.apk**: the Play build, the same app as on Google Play: no screen lock (`lock`, double-tap), no calls in the log and no `update`, and it finds people with Android's contact picker instead of reading your contacts. Play Protect may block either APK when sideloaded in India and some other countries, as both have notification access: install with scanning off, as the install guide says. Both APKs use the same package and key, so either installs over the other.

## What's new

- **Start on the widgets page**: Settings → Widgets → **Start on the widgets page** (`widgets.start`) makes the widgets page the one home opens on. Back and Home return to it, and you swipe sideways for the log. The app selector is on the widgets page too, in the same place and with the same settings as on the log, and a key typed on a keyboard brings up the log with it. The page has no + Add and Edit row then: long-press a widget to arrange them.

## Changed

- **Smoother home**: dimmed lines in the log no longer cost extra to draw as the log scrolls, and the now-playing bar is drawn again only when it moves. Typing an app name no longer looks through every command's description again at each key, and the first `time` or `date` with a place no longer stops the prompt for a moment. Coming back from Settings or Arrange widgets keeps your widgets as they were instead of loading them again, and the header no longer asks Android for the time each time it changes.
- **The app list is kept**: installing, updating or removing an app, a profile turned on or off, and a new language update it as they happen, instead of home reading every app again each time you come back to it. If it's ever out of date, `restart` reads it again.
- **Big scripts in the editor**: undo keeps what each step changed rather than a copy of the whole script, the blinking cursor no longer draws the whole script again, and the colours aren't worked out again when only the cursor moves or the find bar goes to another match.
- **Less work in the background**: home no longer reads the log again for each line that comes while you're in another app; it catches up as you come back. A JavaScript script's time limit no longer checks the clock a hundred times a second while it runs, and now playing no longer asks every player again at each update.

## Fixed

- **Now playing after turning notification access off and on**: the header showed nothing playing until Kolahal restarted. It follows your player again as soon as access is back.
- **A repeating reminder moved by the clocks**: `remind every day 2:30 pills` fired at 3:30 on the night the clocks went forward, and at 3:30 from then on. A reminder set in one time zone kept that zone's time on a trip. It now fires at the time you asked for, in the zone you're in. One set before this version keeps the time it next fires at.
- **The log stopped loading older lines**: after scrolling back to the very start and down again, scrolling back stopped at the newest 400 lines, and tapping an older search result didn't get there. It loads them again.
- **`pins` and `updates`**: an alias or a script could take these names and replace the commands, and `help pins` didn't know the command. They're built-in names now, so an alias or a script called `pins` or `updates` no longer runs when you type it: rename it to keep using it.
- **Widget messages**: **Added Clock**, after adding from the picker, didn't show. After Android restored Kolahal on a new phone, nothing said your widgets needed adding again; the log says so now, and tapping the line opens Settings → Widgets → Arrange widgets.
- **Widgets with the widgets page off**: Arrange widgets said to swipe sideways to a page that wasn't there. It says the page is off now, with **Turn on the widgets page** at the top.
- **Run in the script editor after a failed save**: the editor went on waiting, and when the script's timer ran it later, with the old code, showed that run's lines as if your edits had saved and run. It stops waiting when the save fails.
- **Pictures in the log after turning the phone**: a script's picture was stretched to the wider log, and looked soft. It's decoded again for the new width.
- **The tour's typing demo** kept playing behind other apps if you left the tour open on that page, waking the phone twice a second. It plays only while you can see it.
- **Prompt height**: its label in Settings said "while typing", but it applies with the keyboard up or down. It's **Prompt height (dp)** now.
- **Backups and scripts in one folder**: with `backup dir` and `script dir` set to the same folder, picking another for one of them took away Kolahal's access to it for the other, so `script export` or automatic backups failed until you picked the folder again. It stays allowed while either uses it.
- **`releases` after a first check cut short**: if the first check of a repo stopped before the run finished, the next run notified up to three old releases for it. It shows the latest without notifying again.
- **`script import` and `script export`**: `script import` counted every script already on the phone as updated, with nothing changed. `script export` dropped the settings of another phone's scripts from `kolahal.json`, so a phone importing them got the timers their code suggests, not the ones set for them.
- **`@uses` in capitals**: `-- @uses Clipboard`, or a name after a tab, worked when the script ran, but the editor said it wasn't valid. It doesn't now.
- **An automatic backup too big to save** ended with "tap to pick the folder", and the tap opened a folder picker, which can't help. Only a folder problem offers the tap now.
- **After a script's run ends**: a JavaScript `http.cached` that wasn't awaited could still save its answer, and a run Android stopped didn't count as ended, so what it left going could still change things. Nothing does now.
- **`@on boot` after a restore**: restoring a backup made before the phone last restarted ran the `@on boot` scripts that were on once, with no restart. Backups leave out which restart they last ran for.
- **Day dividers at midnight**: with home open across midnight, "Yesterday" kept saying so, and the day that ended kept no divider or its date, until the lines scrolled away and back. They change at midnight.
- **A hand-edited backup**: a saved log position given as text, such as `{"s": "5"}`, was restored as it was, and reading the log then failed at every start. It's read as the number, or left out.
- **A very big script in the editor**: Kolahal kept all of its text twice while in the background, and Android can stop an app that keeps that much. Past 100,000 characters only the cursor is kept; the editor saves the text as it goes to the background.

**kolahal-0.4.12-mapping.zip** is only for reading crash reports from these builds; you don't need it to install.
