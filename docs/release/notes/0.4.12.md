Kolahal 0.4.12, package `com.mtwabpin.kolahal`, Android 9 or newer. It installs over 0.4.11 and keeps your data and settings.

- **kolahal-0.4.12.apk**: the full build.
- **kolahal-0.4.12-play.apk**: the Play build, the same app as on Google Play: no screen lock (`lock`, double-tap), no calls in the log and no `update`, and it finds people with Android's contact picker instead of reading your contacts. Play Protect may block either APK when sideloaded in India and some other countries, as both have notification access: install with scanning off, as the install guide says. Both APKs use the same package and key, so either installs over the other.

## Fixed

- **Now playing after turning notification access off and on**: the header showed nothing playing until Kolahal restarted. It follows your player again as soon as access is back.
- **A repeating reminder moved by the clocks**: `remind every day 2:30 pills` fired at 3:30 on the night the clocks went forward, and at 3:30 from then on. A reminder set in one time zone kept that zone's time on a trip. It now fires at the time you asked for, in the zone you're in. One set before this version keeps the time it next fires at.
- **The log stopped loading older lines**: after scrolling back to the very start and down again, scrolling back stopped at the newest 400 lines, and tapping an older search result didn't get there. It loads them again.
- **`pins` and `updates`**: an alias or a script could take these names and replace the commands, and `help pins` didn't know the command. They're built-in names now, so an alias or a script called `pins` or `updates` no longer runs when you type it: rename it to keep using it.

**kolahal-0.4.12-mapping.zip** is only for reading crash reports from these builds; you don't need it to install.
