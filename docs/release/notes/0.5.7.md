Kolahal 0.5.7, package `com.mtwabpin.kolahal`, Android 9 or newer. It installs over 0.5.6 and keeps your data and settings.

- **kolahal-0.5.7.apk**: the full build.
- **kolahal-0.5.7-play.apk**: the Play build, the same app as on Google Play: no screen lock (`lock`, double-tap), no calls in the log and no `update`, and it finds people with Android's contact picker instead of reading your contacts. Play Protect may block either APK when sideloaded in India and some other countries, as both have notification access: install with scanning off, as the install guide says. Both APKs use the same package and key, so either installs over the other.

This release finishes the review of the code that 0.5.6 started: mostly speed, and safer handling of scripts, backups and downgrades.

## Faster

- **Typing is lighter again.** A key press no longer reads the command names, the recent commands or the app launch counts again, and suggestion rows that didn't change aren't redrawn.
- **Kolahal starts faster.** Work the first screen doesn't need (unlock counting, the app and call watchers, triggers, contacts) starts after it is shown.
- **Returning home is lighter.** Kolahal listens for widget updates only when a widget is placed, and the alarm and media access checks no longer run on the screen's thread.
- **Icons are there when you come back.** After 10 minutes away, the icons of your 24 most used or pinned apps stay loaded. When the phone runs low on memory, they are still dropped.
- **`log only` and searches like `/@feeds` are faster on a big log**: the database picks the lines before Kolahal reads them.
- **A very long line in the log no longer slows home down**: a folded line lays out only the part it shows.
- **The app selector's rail, the widgets page and the script editor open faster the first time**: Android now compiles them ahead, as it already did for the rest of home.

## Fixed

- **Scripts see today's unlock count.** Without Usage Access, a script could read an old count.
- **When the watchdog must stop one script run, the other runs say what happened.** Each logs what it had waiting and "stopped, because <name> had to be stopped". Before, they disappeared mid-run.
- **A JavaScript run that keeps queuing promise jobs stops at its time limit** ("js: timed out after 60s") instead of running until the watchdog stops all scripts.
- **The "empty log" hint no longer flashes** while the log loads at start.

## Safer

- **A script can no longer run a sensitive command through an alias.** `launcher.run` already refused commands that must be typed. It now checks what your aliases turn into, too.
- **A script's permissions follow its code.** When you save new code that no longer asks for a permission, Kolahal forgets it. If a later version asks for it again, you are asked again. A permission you switched off stays off.
- **Secrets saved before 0.4.0 aren't sent anywhere until you set them again.** Those secrets don't say which sites may receive them. Once, each script that has one logs a line: tap it to set the secret again.
- **A database from a newer Kolahal no longer breaks this one.** It opens as it is, instead of failing each time.
- **A backup from a newer Kolahal imports what this version knows**, and the result says that the rest was skipped.

**kolahal-0.5.7-mapping.zip** is only for reading crash reports from these builds; you don't need it to install.
