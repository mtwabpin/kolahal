Kolahal 0.5.2, package `com.mtwabpin.kolahal`, Android 9 or newer. It installs over 0.5.1 and keeps your data and settings.

- **kolahal-0.5.2.apk**: the full build.
- **kolahal-0.5.2-play.apk**: the Play build, the same app as on Google Play: no screen lock (`lock`, double-tap), no calls in the log and no `update`, and it finds people with Android's contact picker instead of reading your contacts. Play Protect may block either APK when sideloaded in India and some other countries, as both have notification access: install with scanning off, as the install guide says. Both APKs use the same package and key, so either installs over the other.

## New

- **`activity`**: open any screen of an app that other apps may open, not only its main one. `activity settings` lists them, each with its class under it; a tap opens one. `activity settings wifi` opens the one that matches, or lists them when several do. Long-press a line for a command to use in an alias. It works with apps in the personal profile.
- **`wiktionary` in the script library**: a word's meanings from Wiktionary, in any language: `wiktionary serendipity`. One line per meaning with its part of speech, and an example under it when there is one. Its `lang` option picks the language (`script set wiktionary lang German`), or `all`. A word with no entry in your language shows the languages that have one.

## Changed

- **`help` is easier to read**: the command's name alone on the left, a short description beside it, and its arguments muted under it (`on · off · status`), so the left column never wraps. Section names stand out, with a count. `fetch` and `log` have a section now. Lines break only at spaces, never inside a word.
- **`help <command>`** shows the name large, what it does, then one line per use (`todo done <n>`: tick one). A tap on a use puts it in the prompt. `help | grep` also reads the arguments, so `help | grep vibrate` finds `ring`.
- **The app selector**:
  - **No card**: the apps float over home, and the log fades out behind them, so only the wallpaper or the theme's background shows.
  - **Long names end with “…”** before the letter bubble, also on a magnified row, and use the room up to the bubble.
  - **A gentler zoom**: the app at your thumb grows less.
  - **An app is marked only while you pick** (off the edge), where lifting or holding launches it. Sliding along the edge marks none.
- **The calculator's answer shows large while you type**, as Enter logs it: `= 2^10` shows **1024** with `2^10 · tap to continue` under it.
- **`shortcuts `** lists apps as soon as you type the space, the ones you use most first, and only apps that have shortcuts.
- **A script's open card is easier to scan**: one line each for when it runs, how to use it and what it may use, each with an icon. A failure, a missing API key, your edits and a newer version in the library each get their own line, with its button (Add key, Compare, Reset to library, Update). The failure is said once. Each part of a script's summary starts with a capital.

## Fixed

- **The app selector's list stays under your thumb**: lifted near the first or last app, the list no longer jumps to the top or bottom. Left open, it scrolls as far as the strip reaches: the first app down to the strip's top, the last up to its bottom.

**kolahal-0.5.2-mapping.zip** is only for reading crash reports from these builds; you don't need it to install.
