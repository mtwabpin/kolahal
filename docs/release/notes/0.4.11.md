Kolahal 0.4.11, package `com.mtwabpin.kolahal`, Android 9 or newer. It installs over 0.4.10 and keeps your data and settings.

- **kolahal-0.4.11.apk**: the full build.
- **kolahal-0.4.11-play.apk**: the Play build, the same app as on Google Play: no screen lock (`lock`, double-tap), no calls in the log and no `update`, and it finds people with Android's contact picker instead of reading your contacts. Play Protect may block either APK when sideloaded in India and some other countries, as both have notification access: install with scanning off, as the install guide says. Both APKs use the same package and key, so either installs over the other.

## What's new

- **Update from the terminal**: in the full build, `update` says whether a newer release is out, and `update install` downloads it with a progress line above the prompt, checks it's Kolahal's full build signed with Kolahal's key, and opens Android's installer. The first time, Android asks you to let Kolahal install apps. This is the first version that has it, so the first update it can install is the one after 0.4.11. The Play build updates through Google Play.
- **`update` is now a command**: an alias or a script named `update` no longer runs when you type `update`, as the command does instead. Rename it to keep using it.
- **Settings has a shorter main page**: Home screen is now two pages, **Header** and **Widgets**, and Typing is now **Suggestions** and **Keyboard**. **Backup** and **About** have pages of their own, and the Tour is under About. Setting names don't change, so `config`, backups and scripts work as before.
- **Choose what each header shows**: Settings → Header → **Header items** has a box for the full header and one for the one-line header it shrinks to. The clock and the settings button can be turned off too (`header.clock`, `header.settings`). The one-line header's settings are `header.compact.*`, and an item that doesn't fit on its line is left out.
- **Now playing with the header off**: with the header turned off, `header.media-always` keeps what's playing at the top of home, with its progress bar.
- **Material 3 Expressive throughout**: Settings and the other screens outside the terminal use Material's Expressive components. Buttons change shape when you press them, and the theme builder's choices and text fields match the rest.
- **Plainer wording**: text on screen says what other apps say, such as "Enter to apply"; errors say what failed; and one thing has one name. A crash report's button says **Email us**. Library scripts you haven't edited pick up the new wording on the next start, with a line in the log.

## Fixed

- **The one-line header ignored some settings**: it showed the battery even with `header.battery` off, and followed the full header's now playing and status settings. It has its own settings now, and what you'd turned off for the full header starts off there too.

**kolahal-0.4.11-mapping.zip** is only for reading crash reports from these builds; you don't need it to install.
