Kolahal 0.5.11, package `com.mtwabpin.kolahal`, Android 9 or newer. It installs over 0.5.10 and keeps your data and settings.

- **kolahal-0.5.11.apk**: the full build.
- **kolahal-0.5.11-play.apk**: the Play build, the same app as on Google Play: no screen lock (`lock`, double-tap), no calls in the log and no `update`, and it finds people with Android's contact picker instead of reading your contacts. Play Protect may block either APK when sideloaded in India and some other countries, as both have notification access: install with scanning off, as the install guide says. Both APKs use the same package and key, so either installs over the other.

## What's new

- **Kolahal's own scripts are on GitHub too.** The 43 ready-made scripts of the library are now also in the [kolahal-scripts](https://github.com/mtwabpin/kolahal-scripts) repository, as the same files. **Get more scripts** leaves them out, because they are under **Add script → From the library**. Before, a library script you had, such as `aqi`, showed there as "Name taken".
- **Material You in four versions.** Besides **Material You**, three new themes use the same wallpaper colours with another background: **Material You Soft** (one step lighter, near Gboard's keyboard), **Material You Tinted** (some of the wallpaper's main colour in the background) and **Material You Black** (pure black, for an OLED screen). Pick one in **Settings → Look & feel**, or run `theme material-you-soft`. Each follows the wallpaper and dark mode as Material You does.
- **The habit card says "Done today".** Once you mark today, its title line ends with "Done today", beside the green colour. A script can put a few words there too: the new `note` field of a widget, such as `note = "Done today"`.
- **A paused work app asks before it opens.** A tap on an app whose work profile is paused, in the app selector, a search or the log, now asks **Resume work apps?**. **Resume** turns work apps on and opens the app. Before, it wrote a line in the log, which was easy to miss after a tap in the app selector. An app in a locked private space asks **Unlock the private space?**. A typed `open` still prints the line under what you typed.
- **Dark pictures read on a dark theme.** A see-through picture whose lines barely show, such as a diagram or a logo from Wikipedia with dark lines and nothing behind them, now has a light backdrop in the log and in a picture widget. A light one on a light theme gets a dark backdrop. Photos are drawn as they are.
- **Widgets out of sight rest.** A widget scrolled below the fold no longer moves, ticks or runs its `refresh`. It runs as soon as it is back on screen, if its time has passed. A ticking countdown, clock or song now draws only its time each second, not the whole card.
- **Pictures load less often.** A link that gives no picture is tried again after 10 minutes, not at each visit to the widgets page. A large picture in the log no longer pushes the widget pictures out of memory.
- **The editor keeps up with big files.** Find next, Go to line and the flash after a jump no longer lay out the whole file again. Line numbers draw only the lines in view. A very long line, such as minified JSON, is not coloured, so typing in it stays quick. Replace all runs off the main thread, and leaving the editor no longer waits for a slow save to a file in the cloud.
- **The Scripts screens stay calm while scripts run.** The Scripts tab and the library page no longer work everything out again at each run of a script: only a change to a script's code does that, and a card that did not change is not drawn again. The library that comes with the app is read once, in the background, so the first `script install ` no longer stutters.
- **The app selector on the left edge is a true mirror.** With `selector.side left`, each row of the list now has its letter and icon at the right edge of the screen, and the name is aligned toward the strip, as the right edge has it reflected. A magnified row grows from that edge and its name is no longer cut there.
