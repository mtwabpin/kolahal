Kolahal 0.5.5, package `com.mtwabpin.kolahal`, Android 9 or newer. It installs over 0.5.4 and keeps your data and settings.

- **kolahal-0.5.5.apk**: the full build.
- **kolahal-0.5.5-play.apk**: the Play build, the same app as on Google Play: no screen lock (`lock`, double-tap), no calls in the log and no `update`, and it finds people with Android's contact picker instead of reading your contacts. Play Protect may block either APK when sideloaded in India and some other countries, as both have notification access: install with scanning off, as the install guide says. Both APKs use the same package and key, so either installs over the other.

## New

- **Turn off the commands you don't use**: Settings → Commands has a switch for each built-in command. A command that is off isn't suggested or listed in `help`, and its name opens the app it matches: with `maps` off, `maps` opens Maps, and with `yt` off, `youtube` opens YouTube. `help`, `config` and `settings` always stay on. From the prompt: `config set commands.off yt,wiki,maps`.

## Changed

- **Aliases expand as you type**, like abbreviations in the fish shell. Type an alias at the start of the line, then a space, and the prompt shows what it stands for: with `alias a = Authy`, `a` and a space leave `Authy ` in the prompt, ready for Enter or more words. Picking an alias from the suggestions expands it too. Only the first word expands. Enter still runs an alias you didn't expand (`a`, then Enter).
