Kolahal 0.5.1, package `com.mtwabpin.kolahal`, Android 9 or newer. It installs over 0.5.0 and keeps your data and settings.

- **kolahal-0.5.1.apk**: the full build.
- **kolahal-0.5.1-play.apk**: the Play build, the same app as on Google Play: no screen lock (`lock`, double-tap), no calls in the log and no `update`, and it finds people with Android's contact picker instead of reading your contacts. Play Protect may block either APK when sideloaded in India and some other countries, as both have notification access: install with scanning off, as the install guide says. Both APKs use the same package and key, so either installs over the other.

## Changed

- **A new Scripts screen**:
  - **Filters**: a Filter button shows how many are on and opens a sheet of grouped filters: status, how a script runs, where it came from (library, shared, yours), its library version (up to date, new version, edited), what it uses, and its language. Any filter in a group matches; every group you use must match. Each count says how many scripts you'd see if you tapped it. The active filters show under the search, each with a ✕.
  - **Sort**: by name, last run, or recently changed.
  - **Update and Reset on the card**: a copy with a new version shows Update, and one you edited shows Reset, without opening the card. A banner says how many copies differ from the library, with Review and Update all (a list to tick).
  - **Resets keep your settings**: a reset brings back the library's code only. Its timers, options, access and pinning stay. Afterwards a message says what happened, with Undo.
  - **The Library screen** lists your copies that differ first, with Compare and Update or Reset.
  - **Access and event pills** start with a capital and each have an icon, and a long one stays on one line. A card's status preview no longer repeats the script's name.
- **Library scripts you never edited update with Kolahal, always**: Kolahal now knows every version each library script ever had. A copy that is one of them updates at the next start, even an old copy or one restored from a backup, which before stayed "edited" for good. Its timers follow the new version only if you never changed them. A line at the top of the Scripts screen says which scripts updated.
- **An app update ends with ↑**: "Updated Maps ↑", next to + for installed and − for uninstalled. It was ↻, which read as "reload".

**kolahal-0.5.1-mapping.zip** is only for reading crash reports from these builds; you don't need it to install.
