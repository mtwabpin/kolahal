Kolahal 0.5.23, package `com.mtwabpin.kolahal`, Android 9 or newer. It installs over 0.5.22 and keeps your data and settings.

This release has no APKs: while Kolahal is in testing on Google Play, you install and update it from there. That is the Play build: no Assistant, no calls in the log and no `update`, and it finds people with Android's contact picker instead of reading your contacts.

## What's new

- **The versus card is redrawn.** One row per side, with the marks, names and scores in line, so nothing sits off centre any more. Scripts can give each side its own score, a clock that counts down for the side to move (for chess), and up to three short lines such as scorers. A score written as one text, such as "2–1", is split between the sides, so cards from older scripts draw as before. The Cricket script shows each side's score and overs, and Football each side's score with its scorers under it on a large card.

- **An Empty shader template.** `shader save template-empty` starts a shader of your own from just the basics: it draws the screen as it is, with the other inputs listed in a comment.

- **A script can wait up to 60 seconds for a web reply**, for an answer that takes a while: `http.request{ url = …, timeout = 60 }`. Without `timeout` nothing changes.

- **The website has Tools:** a Shader preview that draws your `.agsl` as Kolahal does, and a Script check that says what Kolahal will say about a script before it goes on your phone. Both run in your browser.

## Changed

- **`usage` counts a long session in full.** A stretch of more than six hours in one app with nothing else happening counted as nothing. It counts now: a seven-hour drive with the map on screen is seven hours. Days still start at your midnight.

- **World clocks starts with Tokyo, London and New York** when you haven't set its zones. Set yours with `script set world-clocks zones …`.

- **`usage` shows each app's own name**, not the name you gave it with `rename`, as the Screen time card does.

- **The empty widgets page's picture takes your theme's colors**, on a dark theme too; it was always drawn in Rosé Pine's.

- **Deleting a log line is smooth.** The line fades out while the others close up, and Undo fades it back. While the Undo notice shows, you can scroll the newest line up above it, to delete that one too.

## Fixed

- **A long conversation with the Assistant keeps everything** (full build). It dropped its oldest messages without a word once it grew past a size limit. Each message is kept on its own now; one too large to keep is replaced by a note that says so.
