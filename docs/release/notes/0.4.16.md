Kolahal 0.4.16, package `com.mtwabpin.kolahal`, Android 9 or newer. It installs over 0.4.15 and keeps your data and settings.

- **kolahal-0.4.16.apk**: the full build.
- **kolahal-0.4.16-play.apk**: the Play build, the same app as on Google Play: no screen lock (`lock`, double-tap), no calls in the log and no `update`, and it finds people with Android's contact picker instead of reading your contacts. Play Protect may block either APK when sideloaded in India and some other countries, as both have notification access: install with scanning off, as the install guide says. Both APKs use the same package and key, so either installs over the other.

## Fixed

- **Script secrets**: a script could put a key's placeholder in a site's name (`https://<key>.example.com`). The key then went to the address lookup unencrypted, and the lookup's error showed it to the script. A key can't be part of a site's name now, and an error from a request never shows a key's value to the script, in Lua or JavaScript.
- **Importing a backup** no longer brings in a copy of recent notifications for scripts, or a script's stored values under its number, even when the file has them: this phone's copy stays, and stored values come back by the script's name, as before.

**kolahal-0.4.16-mapping.zip** is only for reading crash reports from these builds; you don't need it to install.
