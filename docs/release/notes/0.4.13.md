Kolahal 0.4.13, package `com.mtwabpin.kolahal`, Android 9 or newer. It installs over 0.4.12 and keeps your data and settings.

- **kolahal-0.4.13.apk**: the full build.
- **kolahal-0.4.13-play.apk**: the Play build, the same app as on Google Play: no screen lock (`lock`, double-tap), no calls in the log and no `update`, and it finds people with Android's contact picker instead of reading your contacts. Play Protect may block either APK when sideloaded in India and some other countries, as both have notification access: install with scanning off, as the install guide says. Both APKs use the same package and key, so either installs over the other.

## Changed

- **Big scripts in the editor**: each key in one costs up to a quarter less, and a script over about 550 lines is coloured around what you're looking at, which makes a key up to four times quicker in a very long script. Scroll far through one and the colours follow once you stop.
- **Smoother home**: new lines show sooner while you type or scroll, a return home no longer waits for Android to check each widget, and dimmed lines with a picture no longer cost extra to draw as the log scrolls. The Scripts page keeps what it read of each script while you're in the editor, so coming back after a save is quicker. Installing or updating an app reloads only that app's icon.
- **Less memory while you're away**: from Android 14, Android never tells the home app it's short of memory, so the pictures and icons kept for scrolling back stayed however long you were away. They go ten minutes after you leave home, as home starts clean after that anyway (`log.fresh`).
- **Feeds** are fetched four at a time: `feed fetch`, Refresh all and an OPML import show their lines sooner, and a feed that doesn't answer no longer holds the rest back. Feeds also take an address with an international name, such as `bücher.de`.
- **Less work in the background**: scripts that run on an event (`@on unlock`, `@on notification`) no longer get slower the longer the phone goes without a restart, and the log's trim after each script run reads a few lines instead of the whole log. A typed command's output no longer waits for ↑ history to be read again.
- **App search** finds a name with ß, ø, ł, æ and the like as you'd type it without them: `strasse` finds Straße.

## Fixed

- **Very big numbers**: `script every x 6405119470038039d` set a timer of a few hours, and a bigger one turned it off; `timer` and `remind` took some huge numbers as a few hours, and others showed an error from Java; `screen-timeout` took one as half an hour. They're refused now.
- **`date +18:30`** showed an error from Java: the furthest offset is 18 hours, and anything past it is no place.
- **Emoji cut in half**: a long notification, a feed's name or a long log line cut short could end in half an emoji, shown as a box.
- **A yearly reminder** set with the phone in Persian, Arabic or Bengali was saved in that language's digits. It still worked, but is saved in plain digits now.
- **`remind feb 29 x`** outside a leap year said it wasn't a time; it's the next 29 February now, as a date without a year is the next time it comes.
- **Compare** showed an extra line for a script saved with Windows line endings.
- **Now playing** could show a time a moment before a track's start.
- **The Scripts page's search field** had a rounder shape than every other field.
- **A notification logged twice**: after Kolahal restarted, or notification access was turned off and on, a notification still showing got a second log line when its app posted it again unchanged.
- **Tapping a notification's line** just after notification access was turned off opened its app instead of what the notification opens.
- **The backup folder**: if Kolahal could no longer open it, for example after a restore on another phone, Settings said no folder was chosen while Back up now failed. It says to pick it again.
- **`apps hidden`** with one hidden app said "1 apps", and the work and private profile lines started in lower case.
- **A feed in UTF-16** whose server named no charset was refused as not a feed, and a feed with one item said "1 items" after its first fetch.
- **A font picked from a file app that names it without an extension**, such as "Mono" or "Iosevka 27.3", was refused as not a .ttf or .otf file. The file itself decides then, as when there's no name.
- **Setup** said "Done" on its button for a moment before the checks had loaded.
- **The script library** could open scrolled to its end, with only its last scripts showing, when the phone was slow to read them.
- **Three-button navigation**: Settings and the other settings pages scrolled their text under the back, home and recents buttons, and the tour's Next and Setup's Continue to terminal sat on top of them. Lists stop at the buttons now, and those buttons sit above them.
- **A log line's time** sat halfway down a line that wraps; it's beside the first line now.
- **`dnd off`** said "Do Not Disturb off" when Do Not Disturb stayed on. Since Android 15, Kolahal can turn off only the Do Not Disturb it turned on: one turned on from quick settings, a schedule or another app stays on, and `dnd off` now says so.

**kolahal-0.4.13-mapping.zip** is only for reading crash reports from these builds; you don't need it to install.
