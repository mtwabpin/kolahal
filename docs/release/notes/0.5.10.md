Kolahal 0.5.10, package `com.mtwabpin.kolahal`, Android 9 or newer. It installs over 0.5.9 and keeps your data and settings.

- **kolahal-0.5.10.apk**: the full build.
- **kolahal-0.5.10-play.apk**: the Play build, the same app as on Google Play: no screen lock (`lock`, double-tap), no calls in the log and no `update`, and it finds people with Android's contact picker instead of reading your contacts. Play Protect may block either APK when sideloaded in India and some other countries, as both have notification access: install with scanning off, as the install guide says. Both APKs use the same package and key, so either installs over the other.

## What's new

- **Examples you can see in the script editor.** The API reference (the question mark in the editor's top bar) shows each kind of widget card as Kolahal draws it, and the log lines that `log`, `md.log` and `fmt` make, each over its code in your script's language. Tap an example to put its code into your script, on lines of its own. The examples are the scripting guide's, and the website now shows them as pictures too.
  - Each `fmt` function's entry shows what it makes, such as a bold word or a row of tags, as the log draws it.
  - Each example is on a panel of its own, and a thin line divides the other entries, so you see at a glance which preview goes with which code.
- **Read a library script before you install it.** On **Add script → From the library**, the code button (`<>`) on a row opens the script: how it runs, what it uses, whether it uses the internet, and its code, read-only and coloured as in the editor, with Install there too. **Get more scripts** shows its code the same way now.
- **Icon buttons say what they do.** Press and hold any icon button, such as **+** and the pencil on the widgets page, the editors' buttons or a feed's refresh, and its name shows in a small bubble above it. A button that already does something on a long-press keeps that, such as the editor's Run (Run with…).
