Kolahal 0.5.14, package `com.mtwabpin.kolahal`, Android 9 or newer. It installs over 0.5.13 and keeps your data and settings.

- **kolahal-0.5.14.apk**: the full build.
- **kolahal-0.5.14-play.apk**: the Play build, the same app as on Google Play: no screen lock (`lock`, double-tap), no calls in the log and no `update`, and it finds people with Android's contact picker instead of reading your contacts. Play Protect may block either APK when sideloaded in India and some other countries, as both have notification access: install with scanning off, as the install guide says. Both APKs use the same package and key, so either installs over the other.

## What's new

- **Apps Android doesn't name.** `usage-summary` called an app "removed" when Android gave Kolahal no name for it. But Android also hides some installed apps from Kolahal, so that could be wrong. Such an app now shows by its package name, with no chip, and its time still counts.
- **Other home apps by name.** Kolahal now asks Android about the other home apps on the phone too, so `usage` and `usage-summary` name them (such as "Pixel Launcher") instead of showing a package.
