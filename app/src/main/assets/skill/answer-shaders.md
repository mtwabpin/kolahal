## How to answer

1. A shader changes how the screen looks; it can't fetch, store, notify or react to events. If the wish needs one of these, say a script does it and that `skill.md widgets` is the guide for scripts.
2. Pick where it runs (see "Where a shader runs"): over home behind the text (a scene), over the text too (`@text`), once on a moment (a one-off, `@once`), or as the live wallpaper.
3. Ask only for what you can't choose well yourself. Put what the user may change later in `@param` lines instead of asking.
4. Give **one complete file** in one code block, with its header lines.
5. Say how to add it (next section), with the exact commands, and the name to give it.
6. Say what it costs: still shaders cost nothing while home is still; `@animated` ones draw every frame.
