Here are all the touch gestures on the home screen:

<GestureMap>

1. **Swipe down on the header**: open the notification shade (`gesture.swipe-down`).
2. **Double-tap empty space**: lock the screen (`gesture.double-tap`). A single tap shows the keyboard.
3. **Pinch the log**: make the text bigger or smaller.
4. **Swipe sideways** on the header, on empty space or on the prompt: open the [widgets page](/guides/widgets/).
5. **Long-press a line**: show its actions. A tap runs its main action.
6. **Swipe a line**: right copies it, left deletes it. You can undo a delete for a few seconds. Deleting a notification's line also [dismisses the notification](/guides/notifications/#deleting-a-line-dismisses-its-notification), once Undo is gone. With the log first in [Page order](/guides/widgets/#page-order), the two trade places, so a swipe toward the pages never deletes. You can change both (see below).
7. **Tap the `$`**: open quick actions.
8. **Swipe up on the prompt**: does nothing unless you set `gesture.swipe-up`.
9. **Slide along the edge**: open the [app selector](/getting-started/basics/#app-selector), if it's turned on.

</GestureMap>

You can change three gestures in **Settings → Gestures** or with `config set`:

| Gesture | Key | Default |
| --- | --- | --- |
| Double-tap empty log space | `gesture.double-tap` | `lock` |
| Swipe down on the header | `gesture.swipe-down` | `shade` |
| Swipe up on the prompt | `gesture.swipe-up` | `none` (off, because it's easy to do by accident) |

Each gesture can have one of these values:

- `lock`: lock the screen.
- `shade`: open the notification shade.
- `quick`: open the quick actions, like tapping `$` on the prompt.
- `none`: do nothing.
- **any command**: Kolahal runs it as if you typed it.

```sh
# swipe up on the prompt for the app list
config set gesture.swipe-up apps -l
config set gesture.double-tap feed read
config set gesture.swipe-down none
```

`lock` and `shade` are also commands. You can type them, make aliases for them or use them in a script command.

What a swipe on a log line does is in **Settings → Log → Swipes**: `log.swipe-left` and `log.swipe-right`, each
`copy`, `delete`, `star`, `fresh` (hide the lines above it), `run` (its command again) or `none`. With `none`, the line
stays still and the swipe turns home's page, if there is one that way. Once you change one, left is left and right is right; while both are
the defaults, they follow the page order as above.

## Locking needs an accessibility service

On Android, an app can only lock the screen through an accessibility service. Kolahal includes a small
service called **Kolahal screen lock** that does only this:

- It is declared with `canRetrieveWindowContent="false"`, so it can't read the screen.
- It asks for no accessibility events, so it doesn't see what you type or what other apps do.
- Its only job is to call the system "lock screen" action. It collects nothing and sends nothing.
- It isn't marked as an accessibility tool, because it isn't one.

Both builds have it, the full build and the Play build. It is off until you turn it on: run `allow lock` or use
**setup → Double-tap to lock**. Before Android's accessibility settings open, Kolahal shows what the service is
for and what it doesn't do, and opens them only if you tap **Allow**. There, find **Kolahal screen lock** and
turn it on. **Not now** opens nothing.

Until you turn it on, `lock`, a lock gesture and the Lock screen quick action show a line you can tap to
ask again.

## Other touch gestures

You can't change these gestures:

- **Pinch** the log to change the text size. When you let go, a short message shows the new size.
- **Tap** empty space to show the keyboard.
- **Drag sideways** across the key bar to move the cursor.

## Wallpaper flash when going home

When you swipe home from an app, you may see your wallpaper for a moment. Your phone's own
launcher causes this, not Kolahal. The [FAQ](/reference/faq/#why-does-my-wallpaper-flash-when-i-go-home) explains why. It also explains how to stop it with three-button navigation or `wallpaper theme`.
