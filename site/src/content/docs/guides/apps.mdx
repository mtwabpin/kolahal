## Launching

To open an app, type part of its name and press Enter. The [basics](/getting-started/basics/#the-prompt)
page explains which app Enter picks. You can also use `open <app>` (alias `launch`). It does the same thing,
and it accepts profile flags:

```sh
open maps
open gmail -w
```

## Listing

```sh
apps                 # grid of chips (alias: ls)
apps -l              # one per line
apps hidden          # only hidden apps
apps -a              # include hidden apps
apps work            # one profile: work, personal, private
```

Tap a chip to open the app. Long-press a chip to see more actions:

- launch
- shortcuts
- app info
- copy package name
- hide
- uninstall
- launch the copy in another profile

## Favourites

You can turn on **Favourites & most-used on empty prompt** (`suggestions.idle`, off by default). Then, when the prompt is empty, the suggestions show your pinned apps first, in the order you pinned them. Your most-used apps come after them.

```sh
pin maps                     # or long-press an app → Pin to favourites
pins                         # grid of pinned apps
unpin maps
```

Pins are saved in the [backup file](/guides/backup/).

## Hide and rename

```sh
hide calculator              # gone from lists, search and suggestions
apps hidden                  # see what's hidden
unhide calculator
rename youtube = yt          # custom label
rename yt =                  # empty restores the original label
rename chrome -w = work web  # flags pick the profile
```

Hidden apps and custom labels are saved in the [backup file](/guides/backup/).

## App shortcuts

Kolahal supports app shortcuts. In other launchers, you see these when you long-press an app icon.
They only work when Kolahal is your default home app.

```sh
shortcuts maps               # list them; tap one to start it
open maps:home               # start the shortcut whose label best matches "home"
```

Shortcuts also appear in the action sheet of every app.

## Aliases

```sh
alias m = open maps          # define
alias                        # list
alias m                      # show one
unalias m                    # remove
```

An alias replaces the first word of a command. Aliases can use other aliases, up to five levels deep,
but they can't form a loop. You can't use a built-in command name as an alias.

## App info and uninstall

```sh
info whatsapp
uninstall some-game -w
```

### Install, update and uninstall log

When you install, update or uninstall an app, the log shows a line for it:

- The first line has the app name, a profile tag and a sign at the end: `+` for install, `↑` for update (a newer version),
  `−` for uninstall. Example: `Updated Maps [W] ↑`.
- The package name and version appear on dimmed lines below.

An update always shows as one line. If you uninstall an app and reinstall it within 20 seconds, that also shows as one line.
Because of this 20-second wait, an uninstall line appears about 20 seconds after the app is removed.
If you return to the home screen after those 20 seconds, it appears then.

If apps change while the launcher isn't running, Kolahal logs the changes the next time it starts.
`installs [<n>]` lists the recent history with dates.

## Screen time and unlocks

```sh
usage            # time per app today (alias: screentime)
usage 7          # last 7 days (1–30)
unlocks          # today's unlock count
unlocks 7        # one line per day for the last week (1–30)
```

`usage` needs **Usage access** (`usage-access`). To count unlocks, Kolahal uses usage access if you granted it.
If not, it counts `ACTION_USER_PRESENT` broadcasts, but only while the launcher is running.
