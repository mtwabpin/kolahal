## What it does

<CardGrid>
	<Card title="Launch apps by typing" icon="seti:shell">
		If your text is not a command, Kolahal matches it against app names. Press Enter to open the best match, which is highlighted. Turn on `suggestions.idle` to see your favourite and most-used apps when the prompt is empty.
	</Card>
	<Card title="An interactive log" icon="list-format">
		Each command and its output form a group with a coloured bar. Tap a line to run its main action.
		Long-press a line to open a menu with copy, share, open, rerun and more.
	</Card>
	<Card title="Scripts in Lua or JS" icon="seti:lua">
		Scripts can run on timers (`every 30m`, `at 08:00`), post notifications, show status lines that you can pin at the top,
		and add `@command` commands that take arguments. Scripts run in a sandbox, in a separate process.
	</Card>
	<Card title="Feeds and notifications" icon="rss">
		Subscribe to RSS and Atom feeds and see unread counts. If you give Kolahal notification access, new notifications
		appear in the log. Each one ends with its app's icon.
	</Card>
	<Card title="Built-in tools" icon="puzzle">
		A calculator and converter (`= 2^10`, `= 5 km in mi`, `= 100 usd in eur`), web search, `call`, `sms`, app shortcuts,
		screen time and an unlock counter.
	</Card>
	<Card title="Work profile and private space" icon="seti:lock">
		If you use them, their apps appear in the same list as your personal apps. Work apps are tagged `[W]`, private space
		apps `[S]` and clones `[C]`. To pause or resume the work profile, use the quick actions or `work off`.
	</Card>
</CardGrid>
